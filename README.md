# 3D Cube Smashing Game

An interactive web-based game that challenges players to destroy colorful 3D cubes in a dynamic environment. Built with vanilla JavaScript and HTML5 Canvas.

## 🎮 Features

- **Two Game Modes**: Casual and Ranked gameplay options
- **Dynamic 3D Graphics**: Smooth animations and realistic physics
- **Special Effects**: Slow-motion sequences and particle effects
- **Scoring System**: Progressive difficulty and combo-based scoring
- **Touch Support**: Works on both desktop and mobile devices

## 🚀 Gameplay

- Swipe or drag to slice through cubes
- Different cube types with unique behaviors:
  - Blue cubes trigger slow-motion
  - Pink cubes require multiple hits
  - Regular cubes for standard points
- Avoid letting cubes fall off-screen
- Chain combos for higher scores

## 🛠️ Technologies

- Pure JavaScript (No frameworks)
- HTML5 Canvas
- CSS3 Animations
- 3D Mathematics & Physics

## 🎯 Installation

1. Clone the repository
2. Open `index.html` in a modern web browser
3. Start smashing cubes!
